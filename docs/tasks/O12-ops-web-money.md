- แท็บกรณีผิดปกติ: การ์ดช่องทาง, คิว, แผงตัดสิน, ผูกใบแจ้งหนี้อื่น, แจ้งลูกค้า (ตามต้นแบบที่กดได้ใน Canvas)

- คืนเงิน เครดิต ใบลดหนี้ และอนุมัติ (แตะกุญแจ · ประวัติ)

**ส่งงาน 2026-11-10** · ops-web test 80 ข้อผ่าน (ใหม่: รายได้ / คืนเงิน 12 ข้อ) · `typecheck` และ `build` ผ่าน

**หน้าที่ทำ**
- **`/payments`** 7 แท็บ (`?tab=`) แทนหน้าเดิมของ A32:
  - **กรณีผิดปกติ**: สรุป 30 วัน, คิว, แผงตัดสิน (หลักฐาน / ดูสลิป / ระบบแนะนำ / ลำดับเหตุการณ์), ผ่าน / ไม่ผ่าน (B6) / ผูกใบอื่น (B7 · บอกยอดเกินหรือขาด) / เก็บเป็นเครดิต / คืนเงินรายการจ่ายซ้ำ · สลิปปกติรอตรวจ: ผ่าน หรือตั้งเป็นกรณีผิดปกติ
  - **เงินเข้า**: ราย 1 วัน มีผู้ยืนยันและสถานะกระทบยอด
  - **ใบแจ้งหนี้**: กรอง / ค้น · สร้าง (B1 · คำนวณยอดสด) · ยกเลิก (B2 · เครดิต / คืนเงิน / ไม่คืน) · ส่งลิงก์จ่าย (B5)
  - **ค้างชำระ**: ประวัติการเตือน, ขั้นถัดไป, ต้องให้คนดู · ติดต่อ (B3) · ขยายเวลา (B4)
  - **ภาษี**: e-Tax ที่ต้องดู (ส่งใหม่) · 50 ทวิ (ดูไฟล์ / ผ่าน / ไม่ผ่าน) · สรุปภาษีขายรายเดือน
  - **คืนเงิน**: ล่าสุด 10 รายการ + ลิงก์หน้าคืนเงิน
  - **รายงานรายได้**: 6 เดือน · ปิดงวดต้องแตะกุญแจ
  - **ส่งออกให้บัญชี (B8)**: ลิงก์ไฟล์ CSV ของ ops-api (ฉบับร่าง / ปิดงวด)
- **`/refunds`**: รออนุมัติ (Owner อนุมัติแตะกุญแจ · ไม่อนุมัติใส่เหตุผล) · ประวัติ · กฎการอนุมัติ · ฟอร์มคืนเงิน (อ้างใบที่ชำระแล้ว) / ให้เครดิต (อ้าง Workspace) · เกินวงเงินขึ้น G7 / G12
- **สิทธิ์**: ผู้ตรวจอ่านได้ ทำรายการไม่ได้ · ทำรายการเงินเฉพาะการเงิน · อนุมัติเฉพาะ Owner
- **เมนู**: รายได้ / กรณีผิดปกติ / คืนเงิน / ส่งออกให้บัญชี เปิดแล้ว

- การ์ดช่องทางชำระและ "ข้อควรรู้" ของแท็บกรณีผิดปกติยังไม่ทำ (ไม่มีข้อมูลสัดส่วนช่องทางใน API) · ส่วน MRR movement อยู่ที่หน้าภาพรวม (O15)
