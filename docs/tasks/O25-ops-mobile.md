หน้าเว็บ (`apps/ops-web/app/(console)/m`)
- `/m` เลือกแท็บแรกตามบทบาท · แถบล่าง อนุมัติ (Owner) · คิวชำระ (การเงิน / Owner) · เหตุขัดข้อง (วิศวกร / Support / Owner) · เมนู (กลับหน้าหลัก) · ปุ่มสูง ≥ 44 px
- M6.1 อนุมัติ: รายการ + "ตัดสินแล้ววันนี้" → รายละเอียด (ยอด · ผู้ขอ · เหตุผล · กฎ · ข้อมูลลูกค้า: วันสมัคร จ่ายกี่รอบ เคยคืนเงินไหม) → อนุมัติต้องยืนยันด้วย Passkey **ทุกครั้ง** (มือถือเรียกยืนยันก่อนเสมอ แม้ยังอยู่ในช่วง 15 นาทีของ G4) → หน้าผล · ไม่อนุมัติกดได้เลย · คำขอของตัวเองทำตามกติกาเดิม (06 › 4)
- M6.2 เหตุขัดข้อง: เลือกสถานะแล้วข้อความแนะนำเปลี่ยนตาม แก้ต่อได้ · อีเมลผู้ติดตาม · อัปเดตที่ผ่านมา · บริการที่กระทบ (จากเหตุที่เปิดอยู่) · ปุ่มเผยแพร่อยู่ล่างจอ · Owner ดูอย่างเดียว
- M6.3 คิวชำระ: สรุป "ยืนยันเองวันนี้" + "ใกล้ครบ SLA" · การ์ดบอกเวลาที่เหลือ (SLA 4 ชม. ทำการ) และคำแนะนำ · bottom sheet มีรายการตรวจ (ยอด สลิป เหตุผิดปกติ) และปุ่มตัดสิน · ผูกใบอื่น / 50 ทวิ / ยอดไม่ตรง → "ทำต่อบนคอมพิวเตอร์" · ตัดสินได้เฉพาะการเงิน
- เมนูผู้ใช้มีลิงก์ "Friday Ops บนมือถือ · แจ้งเตือน" · `manifest.webmanifest` (เพิ่มลงหน้าจอโฮม เปิดที่ `/m`) · service worker ที่ `/ops-sw.js`
- proxy ตรวจ cookie ของ `/m`, `/entitlements`, `/deliveries` ด้วย (O21 / O23 ตกไว้)

Web Push (ops-api `src/push`, migration 0026)
- ตาราง `staff_push_subscriptions` (1 เครื่อง 1 แถว · ปลายทางตอบ 404/410 ลบทิ้ง) และ `staff_push_notices` (กันส่งซ้ำ) · RLS `ops_only`
- ส่งเมื่อ: มีคำขออนุมัติใหม่ (ถึง Owner คนอื่น) · ตัดสินคำขอแล้ว (ถึงผู้ขอ + อีเมล) · เปิดเหตุขัดข้อง (วิศวกร / Support / Owner ยกเว้นคนเปิด) · คิวชำระเหลือไม่ถึง 1 ชม. ทำการ (การเงิน · ครั้งเดียวต่อรายการ · ตรวจทุก 5 นาที)
- กุญแจ VAPID: `OPS_VAPID_PUBLIC_KEY` / `OPS_VAPID_PRIVATE_KEY` · dev / Docker ในเครื่องสร้างจาก `OPS_AUTH_SECRET` ให้เอง (`OPS_VAPID_DERIVE=on`) · production ไม่ตั้ง = ปิด Push (วิธีตั้งอยู่ใน `infra/docker/ops.md`)
- endpoint สรุปสำหรับมือถือ `GET ops/m/approvals` (Owner) · `GET ops/m/payments` (การเงิน / Owner) · การตัดสินใช้ endpoint เดิมที่ตรวจสิทธิ์และลง Audit อยู่แล้ว

ต่างจาก Canvas
- แถบบน (ค้นหา · แจ้งเตือน · เมนูผู้ใช้) ของคอนโซลยังอยู่ด้านบน แทนแถบเวลา/สัญญาณของภาพจำลองโทรศัพท์ · บนจอคอมพิวเตอร์หน้า `/m` แสดงเป็นคอลัมน์กว้าง 480 px
- การ์ด "แจ้งเตือนในมือถือ" ด้านบนสำหรับเปิด/ปิด/ทดสอบ Push ในเครื่อง (Canvas ไม่มีหน้าตั้งค่า)
- M6.3 ตัวเลือก "คืนเงิน" ของจ่ายซ้ำ และ "ผ่าน · ขอ 50 ทวิ" ทำต่อบนคอมพิวเตอร์ เพราะต้องกรอกข้อมูลเพิ่ม (ตามหมายเหตุ Canvas)

ยังไม่ทำ / ข้อจำกัด
- ไม่ได้ทดสอบส่ง Push ถึงเครื่องจริง (ต้อง https หรือ localhost + เบราว์เซอร์ที่เปิดอนุญาต) · test ใช้ตัวส่งจำลอง ตรวจการเข้ารหัสด้วยไลบรารี `web-push`
- แจ้งเตือน "Error rate เกิน" อัตโนมัติยังไม่มี (ต้องมีระบบเฝ้าระวังก่อน) · ตอนนี้แจ้งเมื่อมีคนเปิดเหตุขัดข้อง
