## ทำอะไร

- `/work/[ws]/help` (X1): ค้นหา · หมวด · ยอดนิยม · ติดต่อ Support · สถานะระบบ · ผลค้นหาและไม่พบ (X2) ไฮไลต์ด้วย token `--highlight`
- `/work/[ws]/help/[slug]` (X3): สารบัญ · โหวตช่วยได้ / ไม่ช่วย · "ติดต่อ Support พร้อมแนบบทความนี้" · บทความที่เกี่ยวข้อง · ลิงก์ไปหน้าในแอปใช้ Workspace ปัจจุบัน
- `/(public)/help` และ `/(public)/help/[slug]`: เนื้อหาเดียวกันใช้หัวหน้า Landing (R1) · บทความ "เฉพาะผู้เข้าสู่ระบบ" ไม่แสดง · meta สำหรับ SEO
- แผงช่วยเหลือ (X4): ปุ่ม "?" บนแถบบน หรือกด ? (ไม่ทำงานขณะพิมพ์) · แนะนำบทความตามหน้า · ทางลัด (มีอะไรใหม่ของ W24 · คีย์ลัด · สถานะระบบ) · มือถืออยู่ในเมนู ☰
- ฟอร์มติดต่อ Support (X5): แนะนำบทความระหว่างพิมพ์หัวข้อ · แนบภาพ · แนบหน้าที่เปิดอยู่ + requestId ล่าสุด · ช่องเปิดสิทธิ์เข้าบัญชี (Owner / Admin) · หน้าส่งแล้ว · มือถือเป็นหน้าเต็มจอ
- `/work/[ws]/help/tickets` (X6): รายการ + ข้อความ · ของฉัน / ทั้ง Workspace (Owner / Admin) · ตอบ · ปิด · เปิดใหม่ · สถานะส่งทีมพัฒนาและแก้แล้ว (T12)
- Guest เห็นศูนย์ช่วยเหลือ แต่ไม่เห็นปุ่มติดต่อ Support
- **คำขอนอก lane:** ปุ่ม "?" ผ่านช่องในแถบบนที่ W23 / W24 เตรียม · ลิงก์ในหัวหน้าสาธารณะ (W19)
