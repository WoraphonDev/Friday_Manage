## ทำอะไร

- Ticket: คิวกลาง (รับเรื่องนี้), สร้าง, ตอบ, โอนให้, ส่งต่อทีมพัฒนา, ปิดพร้อมสาเหตุ, SLA และเปิดใหม่เมื่อลูกค้าตอบใน 7 วัน · ลูกค้าส่ง Ticket จากในแอปผ่าน API ฝั่งลูกค้า (คำขอนอก lane ถ้ายังไม่มี)
- สถานะระบบ: uptime, เวลาตอบ, error rate, คิว, การส่ง Email / LINE, Workspace ที่ใช้ทรัพยากรสูง
- เหตุขัดข้อง: เปิด, อัปเดตตามสถานะ, เผยแพร่หน้าสถานะสาธารณะ, ส่งอีเมลผู้ติดตาม
- ปิดปรับปรุง: ตั้งเวลา / เปิดทันที (อ่านอย่างเดียว · ต้องอนุมัติ) · API ฝั่งลูกค้าต้องอ่านสถานะนี้ (คำขอนอก lane)
- งานเบื้องหลังที่ล้ม: ลองใหม่ / ทิ้งพร้อมเหตุผล
