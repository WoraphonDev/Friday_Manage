## ทำอะไร

- **สร้าง:** ซ้ายกรอก (บัญชีลูกค้า · แพ็กเกจ · ที่นั่ง · ราคา / ที่นั่ง / เดือน · 12 / 24 / 36 เดือน · สิทธิ์ตามสัญญา · SLA · ใช้ได้ถึง) ขวาเห็นตัวอย่างเอกสาร · เลขที่ QT-ปปดด-nnnn · ส่วนลดเกินวงเงินของคนกรอก = ขออนุมัติ (ระบบเดิม) · แก้ราคาหลังอนุมัติต้องขอใหม่
- **รายการ:** ต้องทำตอนนี้ = รออนุมัติ + ใกล้หมดอายุ · แท็บ ร่าง · ส่งแล้ว · ตอบรับ · หมดอายุ / ปฏิเสธ · เห็นว่าลูกค้าเปิดดูกี่ครั้ง · ทำสำเนาและแก้ไข
- **ลูกค้าตอบรับ:** หน้า `/quote/[token]` ไม่ต้องล็อกอิน · PDF · ชื่อผู้ลงนาม ตำแหน่ง เลข PO · ขอแก้ไข (เปิด Ticket) · ลิงก์หมดตามวันใช้ได้ถึง
- **ระบบทำต่อให้** (ทีละข้อ ลองใหม่ได้): บันทึกสัญญาในบัญชีลูกค้า · สิทธิ์ตามสัญญา (`entitlement_overrides.contract_ref`) · SLA ตามสัญญา · ออกใบแจ้งหนี้ (#129) · ตั้งเตือนต่อสัญญา 90/60/30 · ย้าย Lead เป็นชนะ
- ไม่อยู่ในงานนี้: e-Signature ตามกฎหมาย · ภาษาอังกฤษ · หลายสกุลเงิน

## บันทึกผล

**ทำแล้ว**
- migration 0060: `quotes` (เลขที่ · บัญชีลูกค้า · ที่นั่ง · ราคาตั้ง / ราคาเสนอต่อที่นั่ง · 12 / 24 / 36 เดือน · สิทธิ์ · SLA · ใช้ได้ถึง · token ของลิงก์ · จำนวนครั้งที่เปิดดู · การตอบรับ · คำขอแก้ไข · ขั้นตั้งค่าหลังตอบรับ) · เฉพาะ Ops
- ops-api `sales/quotes.service.ts`: เลขที่ `QT-ปปดด-nnnn` (ล็อกกันเลขซ้ำ) · คำนวณยอด + VAT 7% · ส่วนลดเกินวงเงินของคนทำ (`limits.discountPct`) = ขออนุมัติ `quote.discount` ก่อนส่ง · แก้ราคาหลังอนุมัติต้องขอใหม่ · ส่ง = สร้างลิงก์ใหม่ + อีเมลผู้ติดต่อ · ทำสำเนา · ต่ออายุ · ผูก Workspace · งานรายชั่วโมงปิดใบที่หมดอายุและลองขั้นที่ค้างใหม่
- API สาธารณะ `GET / POST /public/quotes/:token` (+ `/accept`, `/changes`): ไม่ต้องล็อกอิน · นับการเปิดดู · ตอบรับด้วยชื่อ ตำแหน่ง PO และติ๊กยอมรับ · ขอแก้ไข = เปิด Ticket · ลิงก์ใช้ไม่ได้หลังวันใช้ได้ถึง
- หลังตอบรับระบบทำต่อทีละขั้น (ลองใหม่ได้ · เห็นสถานะแต่ละขั้น): บันทึกสัญญา Enterprise ในบัญชีลูกค้า · สิทธิ์ตามสัญญา (`contract_ref`) · SLA ตามสัญญา · ออกใบแจ้งหนี้ (#129) · เตือนต่อสัญญา 90 / 60 / 30 (ใช้งานเตือนของหน้าต่อสัญญาเดิม) · ย้าย Lead เป็นชนะ · ขั้นที่ต้องมี Workspace รอจนผูก
- เว็บลูกค้า `/quote/[token]`: เอกสารใบเสนอราคา + ปุ่มพิมพ์ / บันทึก PDF (CSS สำหรับพิมพ์) · ฟอร์มตอบรับ · ฟอร์มขอแก้ไข · หมดอายุ / ไม่พบ ชี้ไปฟอร์มติดต่อฝ่ายขาย
- หน้า `/quotes`: ต้องทำตอนนี้ (รออนุมัติ · ใกล้หมดอายุ · ตั้งค่าหลังตอบรับยังไม่ครบ) · แท็บ ร่าง / ส่งแล้ว / ตอบรับ / หมดอายุ-ปฏิเสธ · ตัวแก้ไขซ้ายกรอกขวาเห็นตัวอย่างเอกสาร · แผงขวา ลิงก์ จำนวนเปิดดู และขั้นตั้งค่า · ปุ่ม "สร้างใบเสนอราคา" จากแผงของ Lead · ตัวนับ `quotesDue`
