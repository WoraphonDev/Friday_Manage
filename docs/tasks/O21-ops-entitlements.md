## ทำอะไร

- ตารางฟีเจอร์ / ขีดจำกัด × แพ็กเกจ แก้ได้โดยไม่แก้โค้ด · บันทึกเป็นเวอร์ชันใหม่ (P2) พร้อมจำนวนลูกค้าที่ถูกลดสิทธิ์ก่อนบันทึก · ประวัติ (P3)
- ปรับเฉพาะราย (override): ที่นั่ง พื้นที่ไฟล์ API ต่อนาที Automation ต่อเดือน SSO · ต้องมีเหตุผลและวันหมดอายุ (ยกเว้นสัญญา Enterprise) · เกินแพ็กเกจ 20% ต้องให้ Owner อนุมัติ · เตือนล่วงหน้า 7 วันก่อนหมด
- `plan-limits.ts` ของ API อ่านเวอร์ชัน + override แทนค่าคงที่ (402 เหมือนเดิม)
- รวม Rate limit ต่อลูกค้า (แผนเฟส 2 ใน ComingSoon) เป็นขีดจำกัด "API ต่อนาที"
