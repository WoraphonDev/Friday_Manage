## สิ่งที่ตกลงแล้ว

- ทุกวิธีชำระ (โอน บัตร PromptPay) ไปหน้า `/work/:ws/billing/invoices/:id` · หน้ามี URL กลับมาจ่ายทีหลังได้
- เอกสารทุกใบใช้โครงเดียวกัน: หัวกระดาษ → แถบเหตุผล (เฉพาะใบที่แก้เอกสารเดิม) → กล่องลูกค้า/ข้อมูลเอกสาร → ตาราง → สรุปยอด → แถบข้อมูล 4 ช่อง → หมายเหตุ → ลงนาม → ท้ายหน้า
- ใบกำกับภาษีมีรายการตาม ประมวลรัษฎากร ม.86/4 และประกาศอธิบดีฯ ฉบับที่ 199 (สาขา 5 หลัก) · เลข TX/RC/CN/DN เดินแยกไม่ข้าม · วันที่ใบกำกับภาษี = วันที่ได้รับเงิน (โอน = วันที่ตามสลิป) · ป้าย ต้นฉบับ/สำเนา/ใบแทน (ม.86/12)
- ใบลดหนี้ (ม.86/10) และใบเพิ่มหนี้ (ม.86/9) ส่งให้ลูกค้าทางอีเมลและหน้า Billing
- ข้อความ e-Tax ใช้แบบ e-Tax Invoice & e-Receipt ผ่านผู้ให้บริการ (ตามสเปก `tax_document`)
- รายงานภาษีขาย: หน้า 1 ตามแบบ · หน้า 2 รายละเอียดประกอบสำหรับกระทบยอด · Excel 2 แท็บ

## รอนักบัญชียืนยัน (ทำตามตัวอย่างไปก่อน แก้ที่แม่แบบจุดเดียว)

1. รายการครบตาม ม.86/9, ม.86/10 และประกาศฉบับที่ 195
2. ฉบับใหม่แทนฉบับที่ยกเลิก ลงวันที่ตามฉบับเดิมหรือวันที่ออกใหม่
3. ใบเดิมมีหัก ณ ที่จ่าย ยอดคืนเงินตามใบลดหนี้ต้องหักส่วนนั้นหรือไม่
4. เกณฑ์หัก ณ ที่จ่ายเมื่อยอดไม่ถึง 1,000 บาท (ท.ป.4/2528 ข้อ 12/7) สำหรับค่าบริการรายเดือน
5. คำว่า "เอกสารออกเป็นชุด" บนใบเสร็จรับเงิน/ใบกำกับภาษี
6. รูปแบบคอลัมน์รายงานภาษีขาย
