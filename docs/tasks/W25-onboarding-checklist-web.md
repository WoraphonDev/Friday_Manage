## ทำอะไร

- การ์ดบนสุดของ Home (V1): ความคืบหน้า · ขั้นที่เสร็จขีดฆ่า · ขั้นถัดไปกรอบม่วงพร้อมปุ่มหลัก · กล่อง "ทำไมต้องชวนทีม" + ลิงก์คู่มือ (ไปศูนย์ช่วยเหลือของ W26 ถ้ามีแล้ว ไม่งั้นซ่อน) · ซ่อนได้ต่อคน
- ปุ่ม "เริ่มต้นใช้งาน n/6" ท้าย Sidebar เหนือ Admin Console (V2) เปิด Popover รายการย่อ · "แสดงบน Home อีกครั้ง" · "ไม่ต้องแสดงอีก"
- รายการ 3 ขั้นของสมาชิก (V3) · การ์ดเขียวเมื่อครบ (V4 แสดงครั้งเดียว) · เมนูบัญชีมี "เริ่มต้นใช้งาน" เมื่อซ่อนไว้
- มือถือ: การ์ดย่อบน Home แสดงเฉพาะขั้นถัดไป · "ดูทั้งหมด" เปิด Bottom sheet · รายการในเมนู ☰
- ข้อมูลอัปเดตเองเมื่อกลับมาที่หน้า (refetch on focus) ไม่ต้องรอรีเฟรช
- **คำขอนอก lane:** แทรกการ์ดใน `apps/web/app/work/[ws]/page.tsx` (W03) หนึ่งบรรทัด · วางปุ่มท้าย Sidebar ผ่านช่องใน `workspace-shell.tsx` ที่ W23 เตรียม

**ส่วนประกอบ**
- `home-card.tsx` › `OnboardingHomeCard` (V1 · V3 · V4 · มือถือ) บนสุดของเนื้อหา Home ทั้งจอใหญ่และมือถือ: ความคืบหน้า n / total + แถบ · ขั้นที่เสร็จขีดฆ่า · ขั้นถัดไปกรอบม่วง + ปุ่มหลัก ขั้นอื่นปุ่มรอง · ตัวเลขประกอบ (12 / 10 งาน · 1 / 2 คน · คำเชิญค้าง · ทำแล้วเมื่อวาน) · กล่อง "ทำไมต้องชวนทีม" (ดูโปรเจกต์ตัวอย่าง = เปิดที่มีอยู่หรือสร้างผ่าน `w/projects/sample` · ถาม Support แสดงเมื่อตั้ง `NEXT_PUBLIC_SUPPORT_EMAIL` · ลิงก์คู่มือซ่อนไว้จนกว่า W26 จะมีศูนย์ช่วยเหลือ) · ซ่อนได้ต่อคน
- สมาชิก (V3): หัว "เริ่มใช้งานในทีม …" + ผู้ชวน · 3 ขั้นส่วนตัว · ปุ่ม "เปิดงาน" ไปที่ `p/KEY?issue=KEY-n` และบันทึกขั้นผ่าน `w/onboarding:task-opened`
- ครบแล้ว (V4): การ์ดเขียวแสดงครั้งเดียว (บันทึก `:complete-seen` ตอนแสดง แต่ค้างไว้จนกดปิดหรือออกจากหน้า) · ปุ่ม "เปิด Gantt" ของโปรเจกต์แรกแทน "ดูคู่มือ Gantt" (ยังไม่มีศูนย์ช่วยเหลือ)
- `index.tsx` › `OnboardingNavButton` (V2) ปุ่ม "เริ่มต้นใช้งาน n/6" พร้อมวงความคืบหน้า ท้าย Sidebar เหนือ Admin Console · Popover รายการย่อ + "ถัดไป: …" + "แสดงบน Home อีกครั้ง" (เมื่อซ่อนไว้) + "ไม่ต้องแสดงอีก" · อยู่ใน Navigation จึงขึ้นในเมนู ☰ ของมือถือด้วย · `OnboardingAccountItem` ในเมนูบัญชีเมื่อซ่อน / ไม่ต้องแสดงอีก กดแล้ว `:show` และไปที่ Home
- มือถือ: การ์ดย่อเฉพาะขั้นถัดไป (หัวข้อบอกจำนวนที่เหลือ เช่น "ชวนเพื่อนร่วมทีมอีก 1 คน") + ปุ่มหลัก + "ดูทั้งหมด" เปิด Bottom sheet (รายการทั้งหมด + ไม่ต้องแสดงอีก)
- ข้อมูลชุดเดียว (`useOnboarding` · query `["onboarding", ws]`) ใช้ร่วมกันทั้งการ์ด ปุ่ม Sidebar และเมนูบัญชี · `staleTime: 0` + refetch on focus: กลับมาที่หน้า / เปิด Home ใหม่ / สลับแท็บกลับมาแล้วโหลดใหม่ · กำลังโหลดไม่แสดงอะไร (ไม่ดันเนื้อหา Home) · Error เงียบ (ซ่อนทุกจุด) · Guest ไม่เรียก API · `eligible: false` ไม่แสดงอะไร
- สีจาก token ทั้งหมด (สว่าง / มืด) · ข้อความ EN ครบ (W21)
