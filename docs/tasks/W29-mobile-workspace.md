## ทำอะไร (เฉพาะ ≤760px)

- `MobileHeader` ใช้ร่วม: ไทล์โลโก้ (เปิดเมนู Workspace) · ปุ่มของหน้า · ค้นหา · กระดิ่ง (ไปกล่องข้อความ พร้อมจำนวนยังไม่อ่าน) · หัวข้อ 26 px + คำอธิบาย
- ชุด class `m-*` ใน `globals.css`: การ์ดมุม 16 · KPI 2×2 · หัวส่วน · กลุ่มแถวมุม 14 · ชิปสูง 44 มีตัวเลข · ปุ่มลอย "สร้างงาน" · ใช้เฉพาะ component ที่ render เมื่อ `useIsMobile()`
- หน้าหลัก: การ์ดทักทาย + สรุป (งานวันนี้ · เลยกำหนด · คำขอรออนุมัติ) · KPI งานวันนี้ / เลยกำหนด / ครบกำหนดสัปดาห์นี้ / รออนุมัติ (ของฉัน) · การ์ดเริ่มต้นใช้งาน · คำขอรออนุมัติพร้อมปุ่มตัดสิน · รอคุณรีวิว (ป้ายสถานะ · ผู้ส่ง · กำหนด) · โปรเจกต์พร้อมแถบความคืบหน้าและป้ายเสี่ยง / ล่าช้า · ปุ่มสร้างงานลอย
- งานของฉัน: หัวข้อ "งานของฉัน" + จำนวนงานเปิด · ชิปช่วงเวลา (ตัวกรองแท็บเปิดจากปุ่มกรอง) · กลุ่มตาม Due ในกล่องขอบมน · แถว = ติ๊กปิดงาน · คีย์ + ชื่อ · โปรเจกต์ · MD · กำหนด · ลูกศร
- กล่องข้อความ: ชิป ยังไม่อ่าน / ทั้งหมด / Mentions / มอบหมาย พร้อมตัวเลข · กลุ่มวันในกล่องขอบมน · แถว = จุดยังไม่อ่าน · รูป · ใคร ทำอะไร · ข้อความ / งาน · เวลา · ⋮ เปิด ActionSheet (อ่านทั้งหมด · ตั้งค่าการแจ้งเตือน) · แตะแถวเปิดรายละเอียดเดิม

## ต่างจากต้นแบบโดยตั้งใจ (ไม่มีข้อมูลหรือฟังก์ชันจริงต่างกัน)

- ไม่มีกราฟ "งานที่ปิดได้ 7 วัน" และตัวเลขเทียบเมื่อวาน (API ยังไม่มีข้อมูล) · KPI "เสร็จสัปดาห์นี้" ใช้ "ครบกำหนดสัปดาห์นี้" แทน
- หน้าหลักส่วน "ต้องทำวันนี้" ใช้รายการรอคุณรีวิว (API ให้เฉพาะรหัสงานที่ครบวันนี้ ไม่มีชื่อ)
- งานของฉันใช้ช่องติ๊กปิดงานแทนรูปผู้รับผิดชอบ · ชิปเป็นช่วงเวลาเดิม (วันนี้ + Overdue / สัปดาห์นี้ / ทั้งหมด)
- กระดิ่งพาไปกล่องข้อความ (ยังไม่มีแผงครึ่งจอ)

## บันทึกผล

ส่งงาน 15 พ.ย. 2569 · ไม่เปลี่ยน API

**วิธีทำ** · หน้าหลักและงานของฉันมี component มือถือแยกอยู่แล้ว (`MobileHome`, `MobileTasks` · render เมื่อ `useIsMobile()`) จึงเขียนใหม่ทั้งตัว · กล่องข้อความเพิ่มสาขามือถือใน `InboxPage` (รายการ) และใช้ส่วนรายละเอียดเดิม · คำสั่งตัดสินคำขอรวมเป็นฟังก์ชัน `run` ใช้ร่วมทั้ง desktop และมือถือ (พฤติกรรมเดิม) · หัวข้องานของฉันบนมือถือเป็นไทย "งานของฉัน" ให้ตรงกับแถบล่าง (desktop ยัง "My Tasks")
