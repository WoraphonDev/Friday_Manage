**ส่งงาน 2026-11-10** · ops-web test 77 ข้อผ่าน (ใหม่: Workspaces / รายละเอียด 12 ข้อ, ผู้ใช้ 6 ข้อ) · `typecheck` และ `build` ผ่าน

**หน้าที่ทำ**
- **`/workspaces`**:
  - ค้น, ชิปแพ็กเกจ, เรียง (MRR เฉพาะคนเห็นเงิน), ชิปฟีเจอร์ที่ใช้, หน้าละ 50
  - ตารางตาม Canvas: ที่นั่ง / โปรเจกต์ / ผู้ใช้งาน 30 วัน / พื้นที่ / การเชื่อมต่อ / สุขภาพ / MRR
  - เลือกหลายแถวแล้วขยายทดลองใช้ / ให้คูปองทีละราย (เกินวงเงินขึ้นคำขออนุมัติรายตัว) · ส่งออก CSV (G9)
- **`/workspaces/[id]`**:
  - หัวหน้า: แพ็กเกจ / สถานะ / สุขภาพ / เจ้าของ / สมัคร / Data region / ชื่อนิติบุคคล · แถบสิทธิ์เข้าบัญชี
  - ปุ่มตามบทบาท: C1–C6
  - 9 แท็บ แต่ละแท็บโหลดและล้มแยกกัน (S6) · ภาพรวมมีการ์ดกำไร (เฉพาะคนเห็นเงิน), สัญญาณพร้อมอัปเกรด และบันทึกภายใน
  - แท็บผู้ใช้มีปุ่มโอนความเป็นเจ้าของ (C7)
- **`/users`**:
  - ค้น / กรองสถานะ · กดแถวเปิดลิ้นชักรายละเอียด
  - ปลดล็อก / ส่งอีเมลยืนยัน / ออกจากทุกอุปกรณ์ (G5 + Ticket) · รีเซ็ต 2FA (C10) / เปลี่ยนอีเมล (C11) / ปิดบัญชี (C12) ต้องมีหลักฐานและแตะกุญแจ
  - ปุ่มทำรายการเฉพาะบทบาท Support
- **ลิงก์**: เมนู "ผู้ใช้ทั้งหมด" เปิดแล้ว (`nav.ts`) · ค้นหาทั้งระบบลิงก์ไป `/workspaces/[id]` · ลบหน้า Workspace เก่าของ A32 (`features/workspaces`)

**สิ่งที่ต่างจาก Canvas / คำตัดสิน**
- **C1**:
  - ระยะเวลาเข้าบัญชี (30 นาที – 2 ชม.) ยังไม่มีในหน้า เพราะ `support_sessions` ไม่มีเวลาหมด (ค้างจาก O04)
  - Ticket เลือกจาก Ticket ที่เปิดอยู่ของ Workspace หรือพิมพ์เลขเอง
- **C4**: ยังไม่ออกใบแจ้งหนี้ส่วนต่างอัตโนมัติ (ตาม O02) จึงแสดงหมายเหตุให้ทีมการเงินออกด้วยมือ
- **C6**: ยังไม่มีตัวเลือก "ดูได้แต่แก้ไม่ได้ / ปิดทั้งหมด" (ไม่มีใน API) · การเงินติ๊ก "ค้างชำระตามนโยบาย" ได้
- **C11**: Canvas เขียนว่า "รอคัดค้าน 48 ชม." แต่ API ปัจจุบันเปลี่ยนเมื่ออีเมลใหม่กดยืนยัน (ไม่มีช่วงรอ) · แสดงตามพฤติกรรมจริง
- **C12**: Canvas ระงับ Workspace ที่เป็น Owner คนเดียว แต่ API ปฏิเสธ (`sole_owner`) ให้โอนก่อน · ยังไม่มี "บล็อกอีเมลนี้ไม่ให้สมัครใหม่" (เฟส 3 ตรวจจับการใช้ผิด)
- กราฟผู้ใช้งานรายวันเป็นแท่งจาก `daily_usages` (สี `--chart-primary`)
- **ตรวจด้วยตา** ด้วยข้อมูลจริงใน QA DB ที่ :3003 กับ ops-api :3002 (บัญชี Owner): รายชื่อ, รายละเอียด และลิ้นชักผู้ใช้ ที่ความกว้าง 500 px (หน้าต่าง Chrome ค้างที่ขนาดนี้) → เมนูซ้ายซ่อน ตารางเลื่อนแนวนอน · แก้ตัวเลขในตารางให้ไม่ตัดบรรทัด
- **Docker**: ops-web ยังไม่มี Docker (เหมือน O10)
