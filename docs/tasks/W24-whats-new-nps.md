อ่าน [README](README.md) ก่อนเริ่ม · หน้าจอเป็น**ข้อเสนอ** เริ่มได้เมื่อผู้ใช้อนุมัติไฟล์ 01 แล้ว

## ทำอะไร

- ปุ่มของขวัญบนแถบบน (ซ้ายของ "?" และกระดิ่ง) มีจุดเหลืองเมื่อมีรายการที่ยังไม่เห็น · Popover 400 px (U1) · มือถืออยู่ในเมนู ☰ เป็นหน้าเต็มจอ
- Spotlight (U2): แสดงหลังหน้าโหลดเสร็จ 3 วินาที · ไม่แสดงขณะพิมพ์ เปิด Drawer งาน หรือเข้าใช้ครั้งแรก (ให้ Onboarding ทำงานก่อน) · ปิดแล้วไม่แสดงอีก
- NPS (U3): การ์ดมุมขวาล่างไม่บังงาน 3 ขั้น (คะแนน → คำถามต่อตามกลุ่มคะแนน → ขอบคุณ) · มือถือเป็น Bottom sheet · ไม่แสดงพร้อม Spotlight
- รูปในรายการใช้ `<img>` จาก URL ที่ API ให้ · ปุ่ม "ลองใช้" พาไปหน้าใน Workspace ปัจจุบัน
- ข้อความใน namespace `whats-new` · สีจาก token ทั้งสองโหมด
- **คำขอนอก lane:** วางปุ่มในแถบบนผ่านช่องที่ W23 เพิ่มใน `src/components/shell/workspace-shell.tsx` และเว้นที่ให้ปุ่ม "?" ของ W26
