## ทำอะไร

- **คะแนนรายวัน:** เก็บ `healthScore()` 4 ส่วนทุกวัน · ใช้ดู "↓14 ใน 7 วัน" และเงื่อนไข "ติดกัน N วัน"
- **Playbook:** เงื่อนไขเริ่ม + ขั้น 3 ชนิด (อีเมลอัตโนมัติ · งานของคน · รอ N วัน) มีทางแยกตามผล · ที่มีให้ตั้งแต่แรก: ใช้งานลดลง · ค้างชำระ · ทีมหดตัว · Ticket ค้างเยอะ · ใกล้ต่อสัญญาแต่สุขภาพต่ำ · งานรันทุกเช้า 07:00
- **ต้องทำวันนี้:** ขั้นงานของคนที่ถึงกำหนด (ของฉัน / เลยกำหนด) · เลื่อน / บันทึกผล
- **ตาราง:** แท็บ กำลังดำเนิน · เพิ่งตก · ฟื้นแล้ว · ยกเลิกแพ็กเกจ · ตัวกรอง Playbook · คนดูแล · ส่วนที่ต่ำ · แพ็กเกจ · MRR ขั้นต่ำ · เลยกำหนด
- **แผงขวา:** แถบคะแนน 4 ส่วน · checklist ของ Playbook · บันทึกผลการโทร (ติดต่อได้ / ไม่รับสาย / จะยกเลิก) แล้วไปขั้นถัดไปหรือปิด
- แจกงาน: คนดูแลบัญชีลูกค้า (`customer_accounts.manager_id`) ไม่มีแจก Support ที่ออนไลน์แบบเวียน · อีเมลใช้ระบบส่งและรายชื่อไม่ส่งเดิม (O23) · ขั้นเสนอส่วนลดใช้วงเงินและอนุมัติเดิม

## บันทึกผล

**ทำแล้ว**
- ops-api `src/success/`: รอบเช้า 07:00 (เวลาไทย) เก็บ `health_daily` ของลูกค้าที่จ่ายเงิน (สูตร `healthScore()` เดิม) → ปิด run ของลูกค้าที่ยกเลิก (churned) → เริ่ม Playbook ตามเงื่อนไข "ต่ำกว่าเกณฑ์ติดกัน N วัน" (ปิดแล้วไม่เริ่มซ้ำ 14 วัน) → ขั้นรอที่ครบกำหนด: คะแนน ≥ 60 = ฟื้นแล้ว ปิดเอง
- Playbook เริ่มต้น 5 แบบ: ใช้งานลดลง · ค้างชำระ · ทีมหดตัว · Ticket ค้างเยอะ · ใกล้ต่อสัญญาแต่สุขภาพต่ำ · ขั้นอีเมลส่งเองแล้วข้ามรายชื่อไม่ส่ง (O23) · งานของคนมีทางแยกตามผล (ติดต่อได้ / ไม่รับสาย / จะยกเลิก → ขั้นใดก็ได้หรือปิด)
- แจกงาน: คนดูแลบัญชีลูกค้า → ผู้ดูแลประจำบัญชีของ Support → Support ที่งานค้างน้อยสุด (ออนไลน์ก่อน)
- หน้า `/success`: ต้องทำวันนี้ (ของฉันก่อน · เลื่อน / บันทึกผล) · แท็บ กำลังดำเนิน / เพิ่งตก (ลด ≥ 10 ใน 7 วัน · เริ่ม Playbook เองได้) / ฟื้นแล้ว / ยกเลิกแพ็กเกจ · ตัวกรอง Playbook · คนดูแล · ส่วนที่ต่ำ · แพ็กเกจ · MRR · เลยกำหนด · แผงขวา แถบคะแนน 4 ส่วน + checklist + บันทึกผล · ปุ่มเฟืองแก้ Playbook (Owner) + "รันตอนนี้"
- ตัวนับ `playbookDue` ในเมนู ภาพรวม และแผงแจ้งเตือน
