## ทำอะไร

- ย้ายงานพร้อม Sub-task ไปโปรเจกต์อื่น ได้เลขใหม่ในปลายทาง · Key เดิมพาไปงานใหม่
- เปิดจากเมนู ⋯ ของหน้างาน และแถบเลือกหลายงานในแท็บ Table · หน้าต่างเดียวกัน
- ดูก่อนย้าย: เลขใหม่ การจับคู่ประเภทงาน / สถานะ / Module สิ่งที่ตามไปไม่ได้ คนที่ไม่ได้เป็นสมาชิก และไฟล์แนบ

## คำตอบของผู้ใช้ (รับตามคำแนะนำ)

1. ไฟล์ที่แนบเฉพาะงานที่ย้ายไปโฟลเดอร์ "ย้ายมาจาก <Key>" ของปลายทาง · ไฟล์ที่ใช้ร่วมกับงานอื่นอยู่ที่เดิม
2. คนที่ไม่ได้เป็นสมาชิกโปรเจกต์ส่วนตัวปลายทาง: ติ๊ก "เพิ่มเป็นสมาชิก" ไว้ก่อน · เอาติ๊กออก = เอาออกจากงาน · คนย้ายที่เชิญไม่ได้ต้องเอาออก
3. รอบแรกทำ Story 1 + 2 · Story 3 (สคริปต์ Ops) ต่อทันที

- Key เดิม: เปิดงานตอบ 404 code `issue_moved` พร้อม `details.key` · หน้างานพาไปแท็บเดียวกันของโปรเจกต์ใหม่ (คงตัวกรองเดิม) · ค้นหา Key เดิมเจองานใหม่เป็นผลตรงตัว · ย้ายหลายรอบจำครบทุก Key

- Key เดิมตอบ 404 + code `issue_moved` แทน 301 แบบ `project_moved` เพราะ fetch / proxy บางตัวจัดการ 3xx เอง (ไม่มี Location) และ 301 ถูกแคชได้ · ผู้เรียกที่ไม่รู้จัก code นี้เห็นเป็น "ไม่พบงาน"
