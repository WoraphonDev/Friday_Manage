## คำตัดสินด้านข้อมูล (5 พ.ย. 2569)

| # | เรื่อง | ข้อสรุป |
|---|---|---|
| 1 | BA, Dev หลายคน, Screen ID, FR / NFR, Plan / Actual Start–End | เป็น**ฟิลด์หลักของงาน** (คอลัมน์และตารางเชื่อม) · Custom field ใช้เฉพาะฟิลด์ที่ทีมเพิ่มเอง |
| 2 | หน่วย Capacity | เก็บเป็น**ชั่วโมง** แสดงตามหน่วยของโปรเจกต์ (8 ชม. = 1 MD) |
| 3 | Capacity เก็บที่ไหน | เก็บ**ทั้ง 2 ที่**: Workspace = เวลาทั้งหมดของคน, โปรเจกต์ = ส่วนที่แบ่งให้ · Admin Console เตือนเมื่อผลรวมทุกโปรเจกต์เกิน |
| 4 | Data region | ช่วงแรก**มี region เดียว** (AWS กรุงเทพฯ) แต่เก็บ `data_region` ไว้ · เมื่อเปิด region ที่ 2 ให้แยกฐานข้อมูลงานตาม region ส่วนบัญชีผู้ใช้และ Billing อยู่ส่วนกลาง |
| 5 | Kanban เมื่อ Bug ใช้ Workflow ต่างจาก Task | คอลัมน์ของ Kanban **ผูกกับหมวดของสถานะ** (To do / In progress / Done) และแสดงชื่อสถานะจริงบนการ์ด · กรองเฉพาะ Bug แล้วเห็นคอลัมน์ตาม Workflow ของ Bug |
| 6 | Sub-task ประเมินงานอย่างไร | มี **Size + Man-Day เหมือน Task** · Task ที่มี Sub-task รวม Man-Day จากลูกอัตโนมัติ |
| 7 | Estimate หน้า B แสดง "รวม 18 ชม." | แสดงตามหน่วยของโปรเจกต์ (แก้ข้อความในหน้าจอ) |

## หน้าจอที่แก้ข้อความตามคำตัดสิน (UI v1.0.1 · แก้แล้ว 5 พ.ย. 2569)

ไม่เปลี่ยน Flow หรือ Layout จึงไม่ต้อง Review ใหม่ · แก้บน Canvas และคัดลอกมาที่ `design/canvas/` แล้ว

| หน้า | แก้อะไร | มาจากข้อ |
|---|---|---|
| L2 · Project Settings › Custom fields | แยกเป็น 2 กลุ่ม: "ฟิลด์มาตรฐาน" (BA, Dev หลายคน, Screen ID, FR / NFR, Plan / Actual) ลบไม่ได้ และ "Custom fields ของทีม" | 1 |
| 7 · Members + Workload | ช่องกรอก Capacity ใช้หน่วยเดียวกับหน้าอื่น (แสดง MD ได้ แต่ให้เห็นว่าเท่ากับกี่ชั่วโมง) | 2 |
| B · สร้าง Task / Sub-task | ตารางเทียบ: Estimate ของ Sub-task เปลี่ยนจาก "กรอกเอง" เป็น "เลือก Size / กรอก Man-Day" · "Estimate รวม 18 ชม." แสดงเป็น MD | 6, 7 |

## UI ที่เพิ่มจากคำตัดสินด้านสิทธิ์ (UI v1.0.2 · แก้แล้ว 5 พ.ย. 2569)

| หน้า | เพิ่มอะไร |
|---|---|
| M1 · 403 | ถ้าผู้เปิดเป็น Workspace Owner / Admin ให้แสดงปุ่ม "เข้าร่วมในฐานะ Admin" พร้อมข้อความว่าจะแจ้ง PM และบันทึก Audit log แทนปุ่ม "ขอสิทธิ์เข้าถึง" |
| N1 · Admin Console | รายการโปรเจกต์ทั้งหมด รวม Private ที่ไม่ได้เป็นสมาชิก (ชื่อ, PM, สมาชิก, สถานะ, อัปเดตล่าสุด) พร้อมปุ่มเดียวกัน |
| L2 · สิทธิ์ของแต่ละ Role | ใต้ตาราง: "Guest ที่เป็น Member เชิญคนไม่ได้ แม้เปิดสิทธิ์เชิญสมาชิกให้ Member" |
