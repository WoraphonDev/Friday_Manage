## ทำอะไร

- ภาพรวม: MRR, ARR, ลูกค้าจ่ายเงิน, ทดลองใช้, churn, NRR, MRR movement, งานที่ต้องทำวันนี้ (คิว อนุมัติ SLA เหตุขัดข้อง)
- ธุรกิจและกำไร: กำไรขั้นต้นต่อแพ็กเกจและต่อลูกค้า, ลูกค้าที่ต้นทุนเกินรายได้, funnel, cohort, ช่องทางและค่าหาลูกค้า / LTV, เหตุผลที่ยกเลิก, การใช้ฟีเจอร์, พร้อมอัปเกรด, ค้างรับตามอายุ, รายได้รับล่วงหน้า, คาดการณ์ MRR
- ตั้งค่าต้นทุนต่อหน่วยและกรอกค่าการตลาดรายเดือน (เฉพาะ Owner และการเงิน)
- คำนวณทุกคืนแล้วเก็บใน cache · ตัวคำนวณกำไรต่อลูกค้าเปิดให้ O02 ใช้
