**สิ่งที่ต่างจาก Canvas / คำตัดสิน**
- A3 ยังแนบไฟล์อีเมลต้นฉบับไม่ได้ (API ไม่มีที่เก็บไฟล์) · Legal hold และปุ่ม "เลื่อนการลบ" ของ Workspace ที่รอลบยังไม่มีใน API จึงไม่แสดง
- นโยบายการเก็บข้อมูลเป็นข้อความคงที่ตามหน้าจอ (ไม่มี API)
- ตัวเลข "ยอมรับคุกกี้ไม่จำเป็น" ไม่มีข้อมูล จึงแทนด้วย "เวอร์ชันที่ตั้งเวลาไว้" · ข้อตกลง SLA Enterprise ไม่อยู่ในชนิดเอกสารของ API
- ปุ่ม "ดูหน้าที่ลูกค้าเห็น" ชี้ `NEXT_PUBLIC_APP_URL/legal/{type}` (ค่าเริ่มต้น https://fridaymanage.com)
- Modal ที่เปิดจาก Drawer เดิมไม่บัง Drawer (z-index 51 เท่ากัน) → ตั้ง overlay / dialog / drawer เป็นชั้นเดียวกันให้ลำดับ DOM ตัดสิน
- **ตรวจด้วยตา** ที่ 1440 px กับ ops-api + QA DB: บันทึกคำขอ → ยืนยันตัวตน → ขั้นถัดไป, แจ้งเหตุ (ความเสี่ยงต่ำ) → บันทึกผลประเมิน → ร่างหนังสือ → ปิดเหตุ, สร้างเวอร์ชันข้อกำหนด (ตั้งเวลา 31 วัน) → ยกเลิก · ใช้ cookie แตะกุญแจที่ sign ด้วย dev secret แทน Security key
- **ข้อมูล QA**: คำขอ DSR-0001 (อีเมลสมมติ ไม่มีบัญชี) และเหตุละเมิด #1 (ปิดแล้ว) · เวอร์ชันเอกสารทดสอบถูกยกเลิกแล้ว
- **Docker**: ops-web ยังไม่มี Docker (ตรวจด้วย `next build` + `next start` ที่ :3003)
