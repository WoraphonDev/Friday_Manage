## ทำอะไร (เฉพาะ ≤760px)

- Login / สมัคร / 2FA / รหัสสำรอง (SplitLayout): ซ่อนแผงแบรนด์สีเข้ม · พื้นม่วงอ่อน · ไทล์โลโก้ Friday ใหญ่กลางจอ · การ์ดขาวมุม 22 px · หัวข้อกลาง · ช่อง 48 px ปุ่ม 44 px
- Login: ลิงก์ "ลืมรหัสผ่าน?" ย้ายไปแถวล่างคู่กับ "สมัครใช้งาน" · ไม่แสดงปุ่ม SSO ที่ยังปิดไว้ · ลิขสิทธิ์ / นโยบาย / ข้อกำหนด (เดิมอยู่ในแผงแบรนด์) ย้ายมาใต้การ์ด
- สมัคร: ฟอร์มอีเมลก่อน แล้วจึง "หรือ" + Google และ "มีบัญชีแล้ว? เข้าสู่ระบบ" ท้ายการ์ด · คำอธิบายใต้หัวข้อใช้ "ไม่ต้องใช้บัตรเครดิต" (ข้อความจริงจากแผงแบรนด์)
- 2FA / รหัสสำรอง: ไอคอนโล่ / กุญแจตกแต่งเหนือหัวข้อ
- ลืมรหัสผ่าน / ตั้งรหัสใหม่ / รับคำเชิญ / ลิงก์ยืนยันอีเมล (CardLayout): พื้นม่วงอ่อน · ไทล์โลโก้แทนโลโก้ตัวอักษร · แถบขั้นและไอคอนอยู่กลาง
- Onboarding: ป้าย "ขั้นที่ N จาก 4" เหนือแถบ · ไม่มีกรอบการ์ด หัวข้อชิดซ้าย · แถบปุ่มติดล่างจอ ปุ่มหลักเต็มที่ (ย้อนกลับ / ข้าม อยู่ซ้าย) · ไม่แสดงตัวอย่างอักษรย่อ Workspace
