## ทำอะไร

- **ให้คะแนน:** งานทุก 5 นาทีตรวจสัญญาณแล้วรวมคะแนนต่อ "เรื่อง" (Workspace หรือ IP) · คะแนนรวมถึงเกณฑ์รอตรวจ (70) = เปิดเคส · ถึงเกณฑ์ระงับ (90) = ระงับ Workspace แบบปิดทั้งหมดก่อน แล้วรอคนยืนยันภายใน 24 ชม. (เกินแล้วแจ้ง Owner ซ้ำทุก 24 ชม. ไม่ปลดเอง)
- **กฎ:** อีเมลโดเมนชั่วคราว +30 · สมัครจาก IP เดียวเกิน 5 ครั้ง/ชม. +35 · เชิญอีเมลภายนอกเกิน 50/ชม. +40 · ข้อความเชิญมีลิงก์ภายนอก +24 · ไม่ยืนยันอีเมลใน 24 ชม. แต่ใช้งานหนัก +20 · บัตรถูกปฏิเสธติดกัน (รอ A35b) · ประเทศของ IP ไม่ตรงที่อยู่ (รอฐานข้อมูล GeoIP) · ชนเพดาน API (รอ O51) · ปรับคะแนน เปิด / ปิด และเกณฑ์ได้จากปุ่มเฟือง พร้อมจำนวนที่เจอ 7 วันและ % ที่คนตัดสินว่าไม่ใช่การใช้ผิด (90 วัน)
- **ต้องทำตอนนี้:** เคสรอตรวจ + ระงับอัตโนมัติรอยืนยัน เรียงตามคะแนน · กด "ไม่ใช่การใช้ผิด" จากแถวได้ · กดแถวเปิดแผงขวา (ที่มาของคะแนน + ข้อมูล Workspace) · ปุ่มหลักตามประเภท · ทุกการตัดสินต้องมีเหตุผลและแตะกุญแจ แล้วไปเคสถัดไปเอง · เลือกหลายเคสแล้วตัดสินครั้งเดียวได้
- **ผลการตัดสิน:** ไม่ใช่การใช้ผิด (ปลดที่ระบบระงับไว้ · ไม่เปิดเคสเรื่องเดิมซ้ำ 30 วัน) · ขอยืนยันตัวตน (ระงับแบบอ่านอย่างเดียว + อีเมลขอเอกสาร) · ระงับ (สแปมคำเชิญ: ยกเลิกคำเชิญที่ค้างด้วย) · ลบและบล็อก (ลบแบบกู้คืนได้ 30 วันตามขั้นตอนลบ Workspace เดิม + บล็อก IP / โดเมน) · Workspace ที่จ่ายเงินอยู่ ระบบไม่ระงับเอง และการระงับต้องไปทำที่หน้า Workspace (มีขั้นอนุมัติเดิม)
- **ลูกค้าที่ถูกระงับ:** อีเมลถึง Owner / ผู้รับใบแจ้งหนี้ บอกเหตุผลกว้าง ๆ และวิธี "ขอให้ตรวจใหม่" (ตอบอีเมลนี้ = เปิด Ticket เข้าคิว Support เดิม)
- **รายชื่อที่ถูกบล็อก:** โดเมนอีเมล · IP / ช่วง IP (CIDR) · slug ของ Workspace · API token (O51 ใช้) · ต้องมีเหตุผล วันหมด (หรือถาวร) · ค้นและแบ่งหน้าที่ server · API ลูกค้าปฏิเสธการสมัคร (รหัสผ่าน + Google / Microsoft) และการสร้าง Workspace ที่ตรงรายชื่อ
- **ประวัติ:** แท็บ "ตัดสินแล้ว" กรองประเภท · ผล · คนตัดสิน · ช่วงวัน · คะแนนขั้นต่ำ (เก็บใน URL)
- เก็บ IP ตอนสมัครใน `signup_attributions.signup_ip` · ตัวนับ `abuseOpen` ในภาพรวมและเมนู

## บันทึกผล

**ทำแล้ว**
- ops-api `src/abuse/`: ให้คะแนนทุก 5 นาที (`AbuseService.tick`) · เคสต่อเรื่อง `ws:<id>` / `ip:<address>` · คะแนนไม่ลดเมื่อหน้าต่างเวลาผ่าน · ระงับอัตโนมัติ (ปิดทั้งหมด) + อีเมลลูกค้า + Push Owner / วิศวกร · เกิน 24 ชม. แจ้ง Owner ซ้ำทุก 24 ชม.
- ตัดสิน: ไม่ใช่การใช้ผิด (ปลดเฉพาะที่ระบบ / เคสนี้ระงับ) · ขอยืนยันตัวตน (อ่านอย่างเดียว + อีเมล) · ระงับ (สแปมคำเชิญยกเลิกคำเชิญที่ค้าง) · ลบและบล็อก (ลบแบบกู้คืนได้ 30 วัน + บล็อก IP 90 วัน / โดเมนชั่วคราวถาวร) · หลายเคสครั้งเดียว · พาไปเคสถัดไป
- รายชื่อที่ถูกบล็อก (`abuse_blocks`): API ลูกค้าปฏิเสธสมัคร (รหัสผ่าน + Google / Microsoft) ด้วย `signup_blocked` และ slug ที่บล็อกตอบเหมือนมีคนใช้แล้ว · api_token ยกเลิก token ทันที
- หน้า `/abuse`: ต้องทำตอนนี้ (เลือกหลายเคส) · แผงขวา · แท็บประวัติ (ตัวกรองใน URL) · แท็บรายชื่อที่ถูกบล็อก · ปุ่มเฟืองกฎ (เจอ 7 วัน · % จับผิด 90 วัน) · ตัวนับ `abuseOpen` ในเมนู ภาพรวม และแผงแจ้งเตือน

**ตัดสินเอง / ต่างจาก storyboard**
- ระบบไม่ระงับ Workspace ที่จ่ายเงินอยู่เอง และตัดสินระงับ / ลบจากหน้านี้ไม่ได้ (ต้องไปหน้า Workspace ที่มีขั้นอนุมัติเดิม) · "ไม่ใช่การใช้ผิด" ทำได้เสมอ
- "ลบ" = ลบแบบเดียวกับลูกค้าลบเอง (pending_delete กู้คืนได้ 30 วัน แล้วงานลบถาวรเดิมลบต่อ · ข้าม Legal hold) ไม่ลบทันที
- เคส Workspace เดี่ยวไม่บล็อก IP (อาจเป็น IP ออฟฟิศที่ใช้ร่วมกัน) · บล็อก IP เฉพาะเคสสมัครถี่จาก IP เดียว
- เกณฑ์ของสัญญาณ (5 ครั้ง/ชม., 50 คำเชิญ/ชม., งาน 100 / คำเชิญ 20 ใน 24 ชม.) อยู่ในโค้ด ปรับได้เฉพาะคะแนน เปิด / ปิด และเกณฑ์รวม
- กฎที่ยังไม่มีข้อมูลเปิดไม่ได้: บัตรถูกปฏิเสธ (A35b) · ประเทศของ IP (ยังไม่มีฐานข้อมูล GeoIP) · ชนเพดาน API (O51)
- เพิ่ม API token ในรายชื่อจากหน้านี้ไม่ได้ (ไม่รู้ว่า token ไหน) · ทำจากหน้า Rate limit ใน O51
