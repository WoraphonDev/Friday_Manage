## ทำอะไร (เฉพาะ ≤760px)

- **แท็บโปรเจกต์** ของเมนูล่างไปหน้าใหม่ `/work/[ws]/projects` (ต้นแบบ u.projects): การ์ดโปรเจกต์ + ความคืบหน้า + ป้ายเสี่ยง / ล่าช้า · ตัวกรองแบบแบ่งช่อง ทั้งหมด / มีงานของฉัน / เสี่ยง (ต้นแบบใช้ "ติดดาว" ซึ่งระบบยังไม่มี) · ปุ่มสร้างโปรเจกต์ลอย
- **เมนู Workspace** (เปิดจากโลโก้บนหัว) เป็นแผ่นล่างจอ เนื้อหาเดิมครบ (ค้นหา · เมนู · โปรเจกต์ · สลับ Workspace · ภาษา / ปี / ธีม · ออกจากระบบ)
- **หน้าย่อยทุกหน้า**: ปุ่มย้อนกลับเหลือไอคอนในช่องแตะ 44 · หัวข้อ h1 26 px ตัวหนา · พื้นหน้าสีพื้นหลัง · การ์ด `.card` มุม 16 มีเงา
- **โปรไฟล์ (แท็บ "ฉัน")**: หัว B "โปรไฟล์" · การ์ดสรุปเป็นแถวรูป + ชื่อ · หมวดเป็นชิป · ไม่มีปุ่มย้อนกลับ
- **ค้นหา · สมาชิก**: ช่องค้นหาขอบมน 48 · ผลในกล่องขอบมน · ตัวเลข 2 คอลัมน์
- **ชิปและตัวเลือกแบบแบ่งช่องทุกหน้า**: ชิปสูง 40 เลือกแล้วม่วงอ่อน (เดิมพื้นดำ) · ตัวเลือกแบบแบ่งช่องพื้นเทา ช่องที่เลือกเป็นการ์ดขาว
- **รายละเอียด / สร้างงาน** (ฐาน C): Drawer เต็มจอไม่มีขอบขาว · พื้นเทา · หัวข้อ 20 · สถานะเป็นแคปซูล · ปุ่ม "เสร็จ" เต็มกว้าง 44 · คุณสมบัติ ส่วนเนื้อหา และ Activity เป็นการ์ดมุม 16 · แท็บงานย่อยแบบแบ่งช่อง · ปุ่มสร้างเต็มกว้าง 48
- **หัวโปรเจกต์**: ย้อนกลับไปรายการโปรเจกต์ · ค้นหา · สร้างงาน · หัวข้อ = มุมมองปัจจุบัน · ปุ่ม "มุมมอง · X ▾" เปิด ActionSheet ทุกมุมมองที่มีสิทธิ์ (รวม Timeline / Gantt / Settings ที่เดิมบอกให้เปิดบนจอใหญ่) แทนแถวแท็บ
- **ทุกมุมมองในโปรเจกต์** (Overview · Table · Kanban · Backlog · Timeline · Gantt · Calendar · Files · Members · Dashboard · Reports · Automation · การแก้ไขแผน · Settings) และ **Admin · Billing · Help · Import · สร้างโปรเจกต์ · ถังขยะ**: ขอบหน้า 12 · การ์ด / KPI มุม 16 มีเงา · ชิป / ตัวเลือกแบบแบ่งช่องตามข้างบน
