## ทำอะไร

ผู้ใช้ถามว่าทำ drag and drop เพื่อสร้าง Diagram / Flowchart ได้ไหม แล้วตัดสิน (2026-11-19):

1. ประเภท: ทั้งหมด (Flowchart, ER, สถาปัตยกรรม, ไวท์บอร์ด) ผสมรูปทรงในภาพเดียวได้
2. ผูกกล่องกับงาน: ไม่บังคับ · 1 งานต่อกล่อง · สีกรอบและชิปตามสถานะงานสด
3. อยู่ที่แท็บใหม่ "Diagram" ของโปรเจกต์ (ต่อจาก Files)
4. แก้ไขทีละคน (ล็อก) · Admin ของโปรเจกต์ "แก้ไขแทน" ได้
5. ไม่มีประวัติเวอร์ชัน มีแค่ undo ระหว่างแก้
6. แพ็กเกจ Free ใช้ไม่ได้
7. ไวท์บอร์ดไม่มีปากกาวาดมือ

## บันทึกผล

- เก็บกล่องและเส้นเป็น JSON ก้อนเดียว (`content`) ตามรูปแบบของ React Flow (`@xyflow/react` 12, MIT) · API ตรวจรูปแบบด้วย zod (รูปทรง 16 แบบ, สีเป็นชื่อ token ไม่รับ hex, เส้นต้องต่อกับกล่องที่มี, ไม่เกิน 500 กล่อง / 1,000 เส้น / 1 MB)
- `issue_ids` สรุปจาก content ตอนบันทึก ใช้หา Diagram ของงาน (`?issue=`) โดยไม่ต้องค้นใน JSON
- ล็อก 5 นาที ต่ออายุทุกครั้งที่บันทึกและ heartbeat ทุก 60 วินาที · `revision` กันบันทึกทับหลังถูกแก้ไขแทน · ไม่ใช้ trigger touch เพราะ heartbeat ไม่นับเป็นการแก้
- คนดูเห็นการแก้ของคนอื่นด้วยการดึงใหม่ทุก 5 วินาทีระหว่างมีคนแก้ (Realtime ของ A17 ยังไม่มีตัวรับในหน้าเว็บนอกจากกระดิ่ง)
- API client มีตัวเลือก `planDialog: false` ให้หน้า Diagram แสดงข้อความแพ็กเกจเองแทน Dialog 402 กลางทุกครั้งที่เข้าแท็บ
- แผงรายละเอียดงานมีแถว "Diagram" ลิงก์ไป Diagram ที่มีกล่องผูกกับงานนั้น (ไม่มีก็ไม่แสดงแถว)
- `html-to-image` ตรึง 1.11.11 ตามที่ React Flow แนะนำสำหรับ Export
- ต่างจาก storyboard: ไวท์บอร์ดยังไม่มี "ลูกศรอิสระ" (เส้นต้องต่อระหว่างกล่อง) · Export ยังไม่มีตัวเลือกซ่อนชิปสถานะ · ชื่อ Diagram ยังไม่ขึ้นในช่องค้นหาด้านบน
