## ทำอะไร

- แท็บ Changelog: ตารางรายการ (ร่าง / ตั้งเวลา / เผยแพร่ / ซ่อน) พร้อมยอดเห็นและคลิก · ตัวอย่างที่ลูกค้าเห็น · เขียน / แก้ (U4) พร้อมกลุ่มผู้เห็น (ทุกคน / แพ็กเกจ / Feature flag / Owner และ Admin) · Spotlight ได้ทีละรายการ · ตั้งเวลา · ซ่อน (U7 พร้อมเหตุผล)
- แท็บ NPS: คะแนน · สัดส่วน 3 กลุ่ม · แนวโน้มรายเดือน · แยกแพ็กเกจ · ตารางความเห็นพร้อมตัวกรอง · ติดตาม (U6): หัวข้อ บันทึกภายใน เปิด Ticket ติดตาม (เปิด T1 ที่เติมข้อความให้) · ส่งออก (G9)
- ตั้งค่าแบบสำรวจ (U5) Owner เท่านั้น
- แท็บ "คำตอบตอนยกเลิก" เป็นลิงก์ไป "ธุรกิจและกำไร › เหตุผลที่ยกเลิก" ที่มีอยู่ (ไม่ทำซ้ำ)
- รูปอัปโหลดเข้าที่เก็บไฟล์สาธารณะแยกจากไฟล์ลูกค้า · Audit ทุกการเผยแพร่ / แก้ / ซ่อน
- สิทธิ์: Owner เขียนและเผยแพร่ · Support เห็นความเห็นและติดตาม · การเงิน / ผู้ตรวจเห็นตัวเลขรวม · วิศวกรอ่าน Changelog
- **คำขอนอก lane:** ลงทะเบียน module (O01) · เปลี่ยนเมนู "Changelog และ NPS" เป็นลิงก์ (O10)
